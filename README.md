# Amir

Kinderfreundliche Fahrrad-Wetter-Webseite für Tablets.

Beim Öffnen prüft die Seite das aktuelle Wetter und zeigt sofort:

- 🚲 **Fahrrad sichtbar:** Wetter ist zum Fahrradfahren geeignet.
- 🚫 **Fahrrad durchgestrichen:** Heute lieber nicht.

## Funktionen

- Tablet-optimiertes Layout für Hoch- und Querformat
- Live-Wetter über Open-Meteo
- Standorterkennung mit manueller Ortssuche als Fallback
- Große, leicht verständliche Statusanzeige
- Animationen und Wetter-Effekte
- Keine API-Schlüssel nötig

## GitHub Pages

Die Website besteht aus statischen Dateien und kann direkt über GitHub Pages veröffentlicht werden.
